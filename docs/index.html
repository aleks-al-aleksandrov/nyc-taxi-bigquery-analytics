How far to trust these numbers

Nothing is dropped silently. The source holds 9,071,205 rows for the quarter. 99.40% pass validation; the other 54,224 are kept in staging and labelled with the rule they failed (refunds, reversed timestamps, impossible speeds).

Totals reconcile to the cent. A dbt test fails the build if the tables behind this page disagree with the fact table on trip count or revenue. 53 automated tests run on every build.

Know the limits. Yellow taxis only: no Uber, Lyft or green cabs. Revenue is the total charged to riders, including tolls, taxes and recorded tips. Cash tips are not recorded. Time between trips is not in the data.
